
# Baldej Delights

<img src="https://furiebstvo.ru/image/BaldejDelights.png">

## Overview
**Baldej Delights** is an add-on for Farmer's Delight mod, inspired by russian low-internet 
memes and meme personas such as Azazin Kreet, Ruslan Gitelman and Vitya Mitya.

### New food:

- Onion frenzy (Azazin Kreet)
- Apples in chicken broth (Vitya Mitya)
- Egg barbecue (Azazin Kreet)
- Bobs (Meme candies)
- Fried nails (Ninja Turtles)
- Overcooked pancakes (Yulia Vysotskaya)
- Tomato with maltese cross (Sunboy the Prophet)
